# Code of Conduct

Karakol contributors are expected to keep discussion technical, respectful, and focused on improving the project.

## Expected Behavior

- Be direct and specific.
- Critique code and design, not people.
- Assume security-related reports may involve sensitive context.
- Keep public discussion free of private logs, credentials, or exploit details.

## Unacceptable Behavior

- Harassment or personal attacks.
- Publishing private logs or secrets.
- Deliberately derailing security discussions.
- Submitting malicious code or test fixtures.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct. Severe violations may result in a ban from the project.
